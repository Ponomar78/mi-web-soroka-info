# На MacBook: подвійний клік

Так, можна. Після завантаження папки на **Робочий стіл** програма відкривається подвійним кліком.

## 1. Скачати на робочий стіл

1. Відкрийте: https://github.com/Ponomar78/mi-web-soroka-info/tree/cursor/iphone-service-diag-5241  
2. Зелена кнопка **Code → Download ZIP**  
3. Розпакуйте ZIP  
4. Знайдіть всередині папку **`iphone-service-diag`**  
5. Перетягніть **`iphone-service-diag`** на **Desktop (Робочий стіл)**

Шлях буде приблизно:

`/Users/ВАШЕ_ІМЯ/Desktop/iphone-service-diag/`

## 2. Один раз встановити

Потрібен **Python 3** (якщо немає: https://www.python.org/downloads/ — поставте галочку *Add python to PATH*).

Потім на Desktop у папці `iphone-service-diag`:

1. Подвійний клік **`Встановити один раз.command`**  
2. Якщо Mac напише «не можна відкрити» → правий клік → **Open** → **Open**  
3. Дочекайтесь `Готово`

## 3. Завжди запускати так

Подвійний клік на одне з:

- **`ServiceDiag.app`** — як звичайна програма Mac  
- або **`Запустити.command`**

Відкриється вікно з кнопками: список пристроїв, повний скан, батарея.

## Важливо

| Що | Де |
|----|-----|
| Програма для Mac (USB) | ця папка + подвійний клік |
| Тест NFC кнопкою на телефоні | окрема апка в `ios-app/` (збірка в Xcode) |

Без підключеного iPhone кнопки покажуть помилку кабелю/Trust — це нормально.
